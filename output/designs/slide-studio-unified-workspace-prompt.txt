Use case: ui-mockup.
Asset type: high-fidelity desktop UI concept for the existing Slide Studio presentation editor.
Input image 1: reference image for the current app, its real slide content, navy color palette, familiar layout, and branding; this is a design reference, not an image to preserve pixel-for-pixel.
Primary request: Redesign this editor into ONE cohesive screen where the user can edit slides, write voice narration, select or record a voice, generate speech, adjust captions and transitions, preview, and export without opening modal dialogs. Produce a polished, realistic flat software screenshot, landscape 1920 by 1080 composition, not a photograph of a monitor.

Design a calm, practical professional editing workspace. Retain the dark navy theme, subtle blue-gray dividers, white and muted slate typography, cyan accents for audio, indigo selection and primary actions. Clean modern sans-serif font, sharp readable UI copy, restrained rounded corners, generous spacing, consistent 8-pixel grid. Avoid excessive glowing effects.
